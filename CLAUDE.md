ATURAN DETAIL PRODUK SADEWA ELEKTRONIK
Nomor melanjutkan 68. Aturan 85 adalah pengecualian dari aturan 12, hanya di detail produk.
P. TAMPILAN 69. Detail produk berupa halaman atau panel sendiri, bukan popup kecil. 70. Desktop dua kolom: galeri kiri, info kanan. Mobile satu kolom, foto dulu. 71. Urutan info: kategori, nama, penilaian, harga, status stok, ringkasan, tombol aksi, deskripsi, spesifikasi. 72. Ada tombol Kembali. Tombol Esc menutup. Fokus pindah ke judul saat dibuka. 73. Setiap produk punya alamat hash bernama (huruf, angka, strip). Bisa dibagikan. 74. Produk tidak ditemukan: pesan jujur dan tombol Kembali.
Q. DATA DAN ADMIN 75. Data produk dikelola admin saja: name, price, category, stock, description, rating, ratingCount, specs, images, payUrl. 76. Halaman publik hanya membaca data. Dilarang tombol edit, hapus, atau menu admin di halaman publik. 77. Keamanan admin dijaga Firebase Auth dan aturan Firestore di server, bukan dengan menyembunyikan tombol. Sebelum terpasang, jangan beri kesan sudah aman. 78. Data kosong ditulis [ISI DATA ASLI]. Dilarang mengarang.
R. PENILAIAN 79. Penilaian tampil hanya jika ratingCount lebih dari 0. Format: ikon bintang garis, nilai, jumlah. Contoh pola: [nilai] dari 5 ([jumlah] penilaian). 80. Belum ada penilaian: tulis "Belum ada penilaian". 81. Nilai dan jumlah hanya dari data nyata milik admin. Selalu tampil sebagai angka, bukan warna saja.
S. STOK 82. Status stok: "Tersedia", "Stok menipis", "Habis". Selalu teks dan ikon garis. 83. "Stok menipis" hanya jika stock di bawah batas yang diisi admin. Dilarang "terjual" atau "stok terbatas" tanpa data. 84. Stok habis: tombol Bayar sekarang disembunyikan. Tombol WhatsApp berubah jadi "Tanya ketersediaan".
T. AKSI 85. Dua aksi: "Pesan lewat WhatsApp" dan "Bayar sekarang". 86. "Bayar sekarang" tampil hanya jika payUrl dari admin ada dan berawalan https. Jika belum ada, sembunyikan. Dilarang tombol bayar palsu. 87. Jika payUrl ada: Bayar sekarang pill terisi var(--btn), WhatsApp pill garis. Jika tidak ada: WhatsApp pill terisi sendiri. 88. Tinggi tombol 48px. Mobile lebar penuh. Jarak antar tombol 12px. 89. WhatsApp memakai wa.me dengan nomor asli [ISI DATA ASLI]. Pesan berisi nama produk dan alamat halaman, di-encode dengan encodeURIComponent. 90. Tautan bayar memakai rel="noopener noreferrer". Tidak ada API key rahasia di frontend. 91. Mobile: bar aksi menempel di bawah hanya saat tombol utama keluar layar. Beri padding bawah dan safe area.
U. GALERI, DESKRIPSI, SPESIFIKASI 92. Foto utama aspect-ratio tetap, foto asli, alt menjelaskan isi. Thumbnail maksimal 5, ganti lewat klik, sentuh, dan panah keyboard. Foto pertama langsung dimuat, sisanya lazy. 93. Ringkasan maksimal 25 kata. Deskripsi dari data admin, maksimal 60 kata, paragraf pendek. 94. Spesifikasi berupa tabel dua kolom (th dan td). Maksimal 8 baris terlihat, sisanya "Lihat semua".
V. KODE 95. Isi detail dibuat dengan createElement dan textContent. Dilarang innerHTML. 96. Data produk berupa objek dengan nama field, bukan array berindeks. 97. Animasi buka maksimal 200ms, fade atau cahaya. Hormati reduced motion.
UJI DETAIL PRODUK: buka di 360, 768, 1280. Tekan Tab dari awal sampai akhir. Buka produk yang tidak ada. Uji stok habis. Uji tanpa payUrl. Tekan Esc.
